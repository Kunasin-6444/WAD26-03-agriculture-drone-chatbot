```

     → app/services/ai_service.ask_ai(text, user_id)
         1) rich menu: rich_menu_service.get_rich_menu_preanswer → data/rich_menu_answers/1-6.txt (มีอ้างอิง ตอบทันที)

         2) คำถามต่อเนื่อง: previous_question (คำถามเต็มล่าสุดต่อ user 10 นาที ถ้าข้อความใหม่ ≤ 30 ตัวอักษร)
         3) cache คำตอบ KB 1 ชม. (ไม่ใช้กับคำถามต่อเนื่อง)
     → app/rag/crag_service.run_natural_pipeline
         - intent_router: วิธีใช้งาน/ขอบเขตบอต → ข้อความแนะนำ (บอก 4 พืชหลัก)
         - เส้นทาง: เรื่องกฎ/CAAT (crag_grader.CAAT_KEYWORDS, evidence.is_drone_rule_topic) → ค้นเว็บ CAAT + KB; คำถามข้อมูลปัจจุบัน → เว็บ + KB; อื่นๆ → KB
         - KB: slide_retriever (embedding + BM25 → RRF ระดับหน้า) → page_reranker (MMR, วลีหายาก RETRIEVER_PHRASE_WEIGHT, แถวต่อของตาราง RETRIEVER_TABLE_CONTINUATION)
           คำถามต่อเนื่องค้น 2 รอบแล้วสลับรวม (interleave_evidence)
         - เว็บ: web_fallback (Tavily, โดเมนที่อนุญาต; CAAT = advanced + อ่านคู่มือผู้ขอรับบริการ กพท. ทุกครั้ง CAAT_DESIGNATED_URLS)
         - ตอบ: natural_answer (prompts/natural_answer.txt) โมเดลเขียนข้อความ + [D1]/[W1] → render ตรวจทีละบรรทัด
           (ตัวเลขต้องอยู่ในแหล่ง, claim_consistency: หน่วย/พืช/หัวฉีด (พัดฟ้า=พัดน้ำเงิน)/ประเภทวัชพืช/คำเปรียบเทียบ, table_grounding: ทีละแถวตาราง,
            เรื่องกฎต้องอ้างเว็บ CAAT) ตัดเฉพาะบรรทัดที่ไม่ผ่าน, "ถามกลับ:" เมื่อคำถามกว้าง, เลขหน้า/ลิงก์จาก metadata, หมายเหตุสารเคมีและหมายเหตุ CAAT/ข่าว
         - NOT_FOUND / ทุกบรรทัดไม่ผ่าน / กฎที่อ้างเอกสาร → ค้นเว็บ 1 ครั้งแล้วตอบใหม่; โมเดลล่ม → แจ้งข้อขัดข้อง (app/service_status.py) ไม่บอกว่าไม่มีข้อมูล
```
