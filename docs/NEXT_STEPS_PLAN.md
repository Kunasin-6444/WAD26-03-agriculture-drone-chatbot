1. ให้เจ้าของลอง 6 เมนู/Flex บนโทรศัพท์และคำถาม KB/web แยกกัน ตรวจข้อความมาถึง ลิงก์เปิดหน้าที่อ้างและข้อมูล/หน่วยตรงต้นฉบับ
2. ความขัดแย้ง mock05 ป้องกันแล้วเฉพาะรูปแบบอัตราสูตรเดียวกันที่แสดงสองหน่วย; ตรวจผลจริงและออกแบบเทียบหลักฐานให้ครอบคลุมขึ้นหากยังพบปัญหา ไม่แก้ต้นฉบับเอง
3. ตรวจข้อเท็จจริงเมนูที่ยังไม่ได้ทวนใหม่และ CAAT ปัจจุบันก่อนรับรองความครบถ้วน; ไม่ใช้ผล LINE API เก่าแทนการทดลองจริงหลังแก้
4. หากเจ้าของสั่งวัดชุด live ให้ล็อกโมเดล ปิด fallback กำหนดชุดและจุดหยุด เทียบ retrieval/answer/citation กับต้นฉบับโดยไม่เปลี่ยน gold; ไม่รัน batch จากสิทธิ์เดิม

## ประวัติก่อนแก้ — ผลตรวจรับ Antigravity 1 พ.ย. 2026

**ยังไม่พร้อมปิดส่งงาน** [ข้อบกพร่องและหลักฐานทำซ้ำ](../cache/eval/antigravity_review_20261101/review.md) ไม่ใช้ `dropped=0` แทนความถูกต้องของคำตอบ

1. แก้การยกเว้นชื่ออังกฤษในวงเล็บและการยืมชื่อจากหน้าที่ไม่ได้อ้าง ให้ผูกชื่อ–ค่า–หน่วย–หน้าตามข้อกล่าวอ้างจริง พร้อมรักษา negative cases ในรายงาน
2. จัดการคำตอบที่เอกสารขัดกัน เช่น mock05 อัตรา/หน่วยของสารสูตรเดียวกัน ต้องแจ้งความขัดแย้งและไม่แนะนำทั้งสองค่าเป็นข้อสรุปเดียว ไม่แก้ต้นฉบับ/gold ตาม output
3. แก้ u03 ให้รักษาส่วนประกอบสูตรผสมเมื่อแยก bullet/ย่อหน้า และแก้ focused tests ที่ล้ม 2 ข้อเรื่อง prefix/layout โดยยังจับสาร/ค่า/หน่วย/หน้าผิดได้
4. แก้ตัวเลข latency และข้อสรุปในเอกสารส่งตามผลที่มีจริง; ผูกแหล่งข้อแนะนำเมนู 4–6 แล้วให้เจ้าของลอง LINE/Flex/6 เมนูบนโทรศัพท์ ผล API validation เดิมไม่แทนการส่งจริง

รอบตรวจรับไม่มี live generation/embedding/Tavily/LINE API ใหม่ ไม่ขยาย batch จากสิทธิ์รอบเก่า; `.env` ล่าสุดเป็น `gemini-3.5-flash-lite` มี fallback ผลเก่าด้านล่างเป็นประวัติ

## ประวัติก่อนเปลี่ยนเป็น Flash Lite — 1 พ.ย. 2026

**อัปเดตหลังคำสั่งเจ้าของ:** ใช้ Gemini 3.7 Flash เป็น primary แล้วและถอดแคชคำตอบ/การแชร์ generation; URL หลักฐานยังครบถึง LINE และไม่แถม homepage ในหมายเหตุ CAAT ตรวจ offline แล้ว ไม่มี live ใหม่ ต้องเริ่ม service ใหม่หรือ build/recreate Docker เพื่อโหลดโค้ด/config นี้ SQLite inbox ยังทำหน้าที่คิวและกัน event เดิมซ้ำ ไม่ได้ให้คำตอบเก่ากับข้อความใหม่ [สถานะล่าสุด](CURRENT_STATE.md)

**พร้อมให้ลองในเครื่อง แต่ยังไม่พร้อมปิดส่งงานโดยไม่มีข้อค้าง** ผลตรวจจริงอยู่ที่ [CURRENT_STATE](CURRENT_STATE.md) และ [รายงานรอบนี้](../cache/eval/delivery_audit_20261101/review.md)

1. แก้ false rejection ของ u03 จาก trace รอบนี้: โมเดลแยกอัตราสารตัวแรกเป็น bullet ไม่มี marker และตัวตรวจไปเทียบแถวสารเดี่ยว ต้องรักษาบริบทสูตรผสมพร้อมคงการจับสลับสาร/ค่า/หน่วย/แหล่ง ห้ามแก้ด้วย prompt เฉพาะคำถามหรือให้ผ่านจากเลขที่พบที่อื่น
2. ตรวจและผูกแหล่งข้อแนะนำทั่วไปของ rich menu 4–6 ให้ครบ พร้อมตรวจเนื้อหาปัจจุบันของ CAAT; ผ่าน `natural_answer.render` และเทียบต้นฉบับก่อนยืนยันเนื้อหาครบ ไม่ถือ LINE validation เป็นการตรวจข้อเท็จจริง
3. เว็บ DJI รอบนี้ search timeout และหยุดแล้ว ไม่วน API ซ้ำ; หากเจ้าของสั่งรอบใหม่ ให้กำหนดขอบเขตและแยก retrieval/answer/citation เทียบต้นทาง
4. ให้เจ้าของลองใน LINE: พิมพ์ “เมนู” กดครบ 6 หัวข้อ และลองคำถาม KB/เว็บที่ระบุเรื่องครบ เก็บว่าข้อความถึงเครื่องและหน้าตาอ่านได้จริง การอ่าน webhook active และ API validate ยังไม่ใช่ end-to-end delivery

รอบตรวจสดก่อนเปลี่ยน config วันที่ 1 พ.ย. จบแล้ว: 6 คำถาม, KKU `gpt-5.6-luna` ตาม `.env` ในเวลานั้น ปิด fallback, 29,612 tokens, embedding 3, สำรองเว็บ 5/8 credits; หยุดเมื่อ web timeout ไม่ขยายรอบเอง ผลนี้ไม่ใช่ผล Gemini หลังเปลี่ยน config
LINE API ที่เจ้าของอนุญาตตรวจแล้ว: เมนูตรงโค้ด 6 ปุ่ม, rich menu/Flex/ข้อความ 6 ชุด valid, webhook active; ไม่ได้ส่งข้อความจริง
