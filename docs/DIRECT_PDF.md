# Direct PDF — การทดลองเสริม

Direct PDF เป็นทางเลือกทดลองส่งหลักฐานจาก PDF ให้โมเดลโดยตรง ไม่ใช่ข้อกำหนดของระบบและไม่ใช่งานที่ต้องทำก่อนเจ้าของลองถาม
เส้นทางหลักปัจจุบันยังเป็น text retrieval ดู [ARCHITECTURE](ARCHITECTURE.md)

ยังไม่เปิดการเปรียบเทียบ RAG vs Direct PDF หรือ ingest เอกสารใหม่โดยอัตโนมัติ
หากเจ้าของต้องการทดลองภายหลัง ให้เลือกคำถาม/หน้าเล็ก ๆ กำหนดขอบเขต API แล้วดูความถูกต้อง ความครบถ้วน citation และเวลาร่วมกัน
การส่ง PDF ให้โมเดลไม่ได้ยืนยันว่าอ่านทุกภาพหรือทุกตารางครบ และยังต้องบอกหน้าที่มาของคำตอบ
